# Segnalazioni di sicurezza

Il canale privato e il responsabile delle segnalazioni devono essere indicati
dalla Regione prima del rilascio pubblico. Non è dichiarato uno SLA di risposta.
Questo documento non attesta l’attivazione di un programma di disclosure.

Non pubblicare vulnerabilità sfruttabili, credenziali, cookie, database, log
operativi o dati personali nelle issue. Se GitHub Private Vulnerability Reporting
verrà attivato dal gestore, usare quel canale riservato; la sua presenza non è
presunta da questo file.

La versione è WIP. Usare dati sintetici nelle prove e mantenere il servizio su
loopback finché non siano validati TLS, origine pubblica, account, backup e
configurazione. Il bootstrap non è un reset delle password esistenti. La demo
offline non offre la separazione e l’autenticazione del backend.
